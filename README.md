# El Nido del Fénix Gamer

Sitio web multipágina dedicado a la historia, la cultura y el aprendizaje relacionado con los videojuegos.

> Proyecto personal desarrollado para aplicar y profundizar conocimientos profesionales de desarrollo frontend.

## Estado del proyecto

Actualmente en desarrollo.

## Objetivo

Crear una plataforma que combine contenido sobre videojuegos con ejercicios prácticos de programación, utilizando cada sección para implementar y reforzar diferentes conceptos de desarrollo web.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Diseño responsivo
- Manipulación del DOM
- Git y GitHub

## Funcionalidades actuales

- Menú principal con seis secciones temáticas.
- Navegación hacia páginas independientes.
- Diseño adaptable para computadoras, tabletas y teléfonos.
- Página inicial del Salón de la Fama.
- Generación dinámica de contenido mediante JavaScript.
- Elementos de accesibilidad como etiquetas `aria-label` y navegación por teclado.

## Secciones del proyecto

- Gremio del Fénix
- Crónicas del Gaming
- Academia del Nido
- Salón de la Fama
- Sala de Arcade
- Expediente del Profesor

## Aprendizajes aplicados

Durante el desarrollo de este proyecto se practican:

- Estructura semántica de HTML.
- Organización de archivos y rutas.
- Diseño con CSS Grid y Flexbox.
- Eventos e interacción con JavaScript.
- Selección y creación de elementos del DOM.
- Uso de objetos y arrays para generar contenido.
- Control de versiones con Git.

## Próximos pasos

- Añadir nuevos pioneros de la historia del gaming.
- Desarrollar las demás secciones.
- Mejorar la accesibilidad y el diseño responsivo.
